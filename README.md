# Updated Portfolio

This package is a rebuilt, hiring-focused static portfolio.

## Main improvements
- New uploaded portrait used throughout the portfolio.
- Modern responsive visual system and navigation.
- NaviDo added as the flagship software project.
- Software work is prioritized before design archive content.
- Arbitrary skill percentages were replaced with technology groups.
- Work experience was condensed and rewritten for software/front-end relevance.
- Graphic design, motion and GIF work are now separate curated galleries.
- Existing Formspree contact form endpoint is preserved.
- Dead placeholder social links and nationality were removed.

## Run locally
Open `index.html` directly, or run any small local web server in this folder.

## Publish
Upload the folder contents to Netlify or your current static hosting target.


## English / Turkish
The portfolio is bilingual. English pages live at the site root and complete Turkish versions live under `/tr/`. Every page includes an EN/TR language switch and `hreflang` alternate metadata.

## Netlify
This is a static HTML/CSS/JavaScript site. `netlify.toml` publishes the repository root directly; no npm/React build is required.
